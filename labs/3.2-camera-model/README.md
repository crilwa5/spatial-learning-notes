# 3.2 Camera Projection Lab

## 实验目标
世界坐标、相机坐标、像素坐标之间的转换。

## 核心公式
P_c = R_cw @ P_w + t_cw

p = K @ P_c

pixel = (p_x / p_z, p_y / p_z)

## 像素反投影
像素先反投影成相机坐标射线，已知深度后才能恢复三维点。

## 运行
python labs/3.2-camera-model/camera_lab.py

## 实际结果

## 遇到的问题与解决

1. 一开始分不清 t_cw 和相机中心 C_w
   - 解决：相机中心 C_w = -R_cw.T @ t_cw
   - 当 R_cw 是单位矩阵时，t_cw = -C_w

2. 一开始把 K @ P_c 的结果直接当成像素
   - 解决：K @ P_c 得到的是齐次像素向量
   - 必须除以第三个分量，才得到真正的 (u, v)

3. 一开始不理解像素为什么不能恢复三维点
   - 解决：像素只给方向，不给深度
   - 一个像素只能确定一条射线

4. 重投影误差为什么是 0
   - 解决：本次是合成数据，内参、外参、深度都一致，且没有噪声
   - 真实数据中可以有误差，通常接近 0 但不一定等于 0
