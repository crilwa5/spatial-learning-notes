# 3.2 Camera Model Notes

这里记录相机投影、反投影和重投影误差的理解。
## 1. R_cw 和 t_cw 分别做什么？

R_cw 是世界坐标到相机坐标的旋转矩阵。它把一个用世界坐标描述的方向或点，旋转到相机坐标的朝向。

t_cw 是平移向量。点先经过 R_cw 旋转，再加上 t_cw，得到相机坐标中的位置。它们共同完成：

P_c = R_cw @ P_w + t_cw

相机中心在世界坐标中的位置可以表示为：

C_w = -R_cw.T @ t_cw

所以外参不仅描述相机在哪里，也描述相机朝哪个方向看。


## 2. 世界坐标怎么到相机坐标？

使用外参变换：

P_c = R_cw @ P_w + t_cw

其中：

- P_w：世界坐标点；
- R_cw：世界坐标到相机坐标的旋转；
- t_cw：平移；
- P_c：相机坐标点。


## 3. 相机坐标怎么到像素坐标？

先用内参矩阵 K 投影，得到齐次像素向量：

projected_h = K @ P_c

然后做透视除法：

u = projected_h[0] / projected_h[2]
v = projected_h[1] / projected_h[2]

最后得到：

pixel = [u, v]

这里的除法很重要，因为投影后得到的是齐次坐标，不能直接当作普通像素坐标。


## 4. 为什么像素只能变成射线？

因为像素只告诉我们在图像中的位置，也就是一个方向。它没有告诉这个方向上的深度。

从相机中心出发，经过这个像素的方向上有很多点，它们都会投影到同一个像素。因此一个像素只能对应一条射线，不能直接对应一个确定的三维点。


## 5. 为什么恢复三维点需要深度？

因为射线只给方向，深度决定沿这条射线走多远。

ray_c 是相机坐标射线，约定 z 分量为 1。已知深度 depth 后：

P_c = ray_c * depth

这样才得到一个确定的相机坐标点，再通过外参转回世界坐标。


## 6. 重投影误差为什么应该接近 0？

因为我们先把世界点投影成像素，再用这个像素和深度恢复世界点，然后把恢复出的世界点重新投影。

如果：

- 相机内参正确；
- 相机外参正确；
- 深度正确；
- 没有数值误差；

那么重新投影应该回到原来的像素，误差接近 0。

在真实数据中，因为图像噪声、标定误差、位姿误差和深度误差，误差不一定为 0。重投影误差是用来检查相机、三维点和观测是否一致的重要指标。


## 7. 这次亲手写代码后多理解了哪一点？

只看概念时，我知道“世界坐标到相机坐标再到像素”是一条流程；亲手写代码后，我真正看清了每一步的数据形状和含义。

尤其是：

- R_cw @ P_w + t_cw 得到相机坐标；
- K @ P_c 得到齐次像素向量；
- 透视除法后才得到 (u, v)；
- 像素反投影只能得到射线；
- 射线必须结合深度才能恢复三维点；
- 重新投影可以检查整条链路是否一致。
